The owner approvals above do not record any sign-off by Dr. Iyad. The existing protocol still requires his own acceptance for:

Merging PR #2 is not itself gated on Dr. Iyad in the repository's rules, but it must be done by a human: agents never merge their own PRs (`CLAUDE.md`).

Any changed scientific decision requires a new log row specifying date, requester, approving reviewer, rationale, affected protocol version and impact on published comparisons.
